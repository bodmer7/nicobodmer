Geo-Quiz

Orte auf der Karte schätzen.

Ausgangslage
Die eigene Region kennt man vom Velo und vom Zugfenster. Auf einer leeren Karte findet man sie trotzdem nicht.
Umsetzung
Eine Quiz-App, in der man Orte auf einer unbeschrifteten Luftbildkarte antippt. Gewertet wird nach Distanz zum richtigen Punkt.
Ergebnis
Live-Webapp mit acht Fragen pro Runde, Luftbildern von swisstopo und eigenem Logo.

Technik: Vite, TypeScript, Leaflet, OpenStreetMap, swisstopo, GitHub Actions und Pages

Geo-Quiz ausprobieren

Health-Dashboard

Daten der Sportuhr im eigenen Überblick.

Ausgangslage
Die Sportuhr sammelt jeden Tag Gesundheitsdaten, die in der Hersteller-App liegen bleiben.
Umsetzung
Ein lokaler MCP-Server macht die Daten schreibgeschützt zugänglich. Daraus entsteht jeden Morgen automatisch ein Dashboard.
Ergebnis
20 schreibgeschützte Abfragen und ein Dashboard mit Readiness, Schlaf, Erfolgen und Gewichtsziel. Der Screenshot zeigt Beispieldaten.

Technik: MCP, Python, SQLite, Jinja2, Playwright

In Arbeit: eine Prognose-App.
